# Receipt Shoebox (UGREEN AI NAS Skill)

UGOS Skill that sorts household receipts, bills, and tax slips into a year-end folder, writes a plain summary, and lists missing document types.

Built for UGREEN Hackathon 2026 on AI NAS, Automate Your Workflow track. Solo entry by John Khan. Round 1 needs PDF + ZIP only (no NAS runtime).

## Free kit

The official starter kit downloaded without an account from:

`https://cdn.shopify.com/s/files/1/0630/9416/1602/files/uliya-skill-kit-0.7.3-en.zip?v=1790578898`

Guide page: https://ai.ugreen.com/pages/hackathon-starter-kit

## Skill package

Uploadable skill directory: `receipt-shoebox/`

Static check was run with the official free UGOS Skill Creation Tool checker (downloaded separately from the starter-kit page). Latest result: `static-pass` (0 errors, 0 warnings). Saved in `check-result.json`.

Round 1 ZIP: `receipt-shoebox-round1.zip` (skill folder only).

## Limits

A static pass does not prove upload, installation, or NAS runtime. Round 2 (finalists) gets remote NAS time.
