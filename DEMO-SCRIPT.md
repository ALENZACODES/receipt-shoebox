# Demo script (optional for Round 1)

Round 1 needs only the proposal PDF and the Skill ZIP. Finalists record a video of no more than 3 minutes on the assigned NAS day. Outline:

1. Show the source folder on the NAS and name the inputs.
2. Run the Skill and show the plan: copy map, possible duplicates, other year files, unscanned files, missing types.
3. Approve, then open the destination folder and the saved summary.
4. Run it on an empty folder to show the empty result.
