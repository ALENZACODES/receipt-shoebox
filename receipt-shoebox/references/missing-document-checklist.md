# Missing document checklist

Compare extracted document types against the user-supplied `needed_types` list. Report each needed type as Found or Missing using verified extraction only, and list the files behind each Found type. If `needed_types` was not provided, skip the missing list and say so in the summary. An empty found set is a valid empty result.

A Missing line is a prompt to look, not a claim that the document exists. Many people receive only a few slip types in a year.
